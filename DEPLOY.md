# Как выложить сайт в интернет навсегда (инструкция для АТП Ивангород)

Сейчас сайт работает на временной ссылке предпросмотра. Она подходит для проверки,
но может измениться. Чтобы у пассажиров была постоянная ссылка, сайт нужно один раз
выложить на бесплатный хостинг. Ниже — самый простой путь: GitHub + Neon + Vercel.
Всё бесплатно, справится даже новичок. Время: примерно 30 минут.
Никаких команд в терминале вводить НЕ нужно — сайт настроит базу сам при первом открытии!

## Что получится в итоге

- Постоянная ссылка вида `https://atp842.vercel.app` — работает всегда, можно печатать на остановках.
- При желании — свой красивый адрес вида `842bus.ru` (платно, ~1000 ₽/год, шаг 4).
- База данных с расписанием тоже переедет на бесплатный облачный PostgreSQL.

## Шаг 1. Залить код на GitHub

1. Зайдите на https://github.com и войдите (у вас уже есть аккаунт).
2. Создайте новый репозиторий: `+` → New repository → имя например `atp842-schedule` → Create.
3. Скачайте код этого проекта из песочницы себе на компьютер (целиком, все файлы и папки).
4. На странице репозитория нажмите «uploading an existing file» и перетащите туда все файлы проекта.
   Внизу нажмите Commit. Готово — код на GitHub.

Важно: файл `.env` (если он есть в скачанном проекте) на GitHub заливать НЕ нужно —
адрес базы вы введёте отдельно на шаге 3.

## Шаг 2. Создать бесплатную базу данных (Neon)

1. Зайдите на https://neon.tech → Sign up (можно через GitHub) → Create project.
2. После создания откройте Dashboard → Connection string → скопируйте строку вида:
   `postgresql://user:password@ep-xxx.neon.tech:5432/app_db?sslmode=require`
3. Сохраните её — она понадобится на шаге 3 (это адрес базы, держите в секрете).

## Шаг 3. Выложить сайт на Vercel (получить постоянную ссылку)

1. Зайдите на https://vercel.com → Sign up через GitHub.
2. Add New → Project → выберите репозиторий `atp842-schedule` → Import.
3. В разделе Environment Variables добавьте переменную:
   - Name: `DATABASE_URL`
   - Value: строка из шага 2 (целиком, вместе с `?sslmode=require` на конце).
4. Нажмите Deploy. Через 1–2 минуты получите постоянную ссылку вида `https://atp842.vercel.app`.
5. Откройте эту ссылку — при первом открытии сайт сам создаст таблицы, расписание
   и пользователей. Всё, переезд закончен!

Стартовые входы после переезда (смените их сразу же, см. «После переезда»):
- Кабинет: `ваш-адрес/kabinet-842`
- admin / ivangorod842, dispatcher / dispatcher123

## Шаг 4 (необязательно). Свой домен вида 842bus.ru

1. Купите домен у регистратора (например, reg.ru или beget.ru).
2. В Vercel: Project → Settings → Domains → Add → введите домен → следуйте подсказкам
   (прописать 2 DNS-записи у регистратора).
3. Через 10–60 минут сайт откроется по красивому адресу. QR-коды на сайте
   перегенерируются сами — ничего править не нужно.

## После переезда

1. Откройте секретный адрес кабинета `ваш-адрес/kabinet-842` (храните отдельно,
   на сайте ссылок на него нет), войдите под admin и **сразу смените пароли**
   во вкладке «Пользователи».
2. Загрузите заново свой баннер и фото (вкладка «Аншлаг и контакты» → «Картинки аншлага»):
   в новой базе их пока нет. Дальше они хранятся в базе и никуда не денутся.
3. Откройте страницу `ваш-адрес/poster` → распечатайте плакат с QR → повесьте на остановках.
4. Разместите ссылку в VK, MAX и на busfor.ru.

## Если что-то не работает

- «Ошибка соединения с базой» → проверьте, что переменная DATABASE_URL введена целиком,
  вместе с `?sslmode=require` на конце. После исправления: Vercel → Deployments → Redeploy.
- Пустое расписание → откройте сайт ещё раз и подождите минуту (первая настройка занимает время).
- Забыли пароль admin → откройте базу в Neon (SQL Editor) и попросите помощника подсказать,
  как сбросить пароль через SQL.
